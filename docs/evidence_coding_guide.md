# Evidence coding guide

Code an outcome `Reported positive` only when the publication reports affirmative evidence for that outcome in the graft. Use `Reported negative` when the outcome was assessed and explicitly absent or unsuccessful. Use `Not assessed` when methods did not evaluate it, `Not reported` when reporting is insufficient, and `Unclear` when interpretation cannot be resolved.

`Functional outcomes` describes the measured endpoint (for example size-selective tracer sieving, visual response, or neuronal activity). It does not imply organ replacement. `Vascularization reported` can include host-derived or chimeric perfusion and should be interpreted with `major_limitations`. “Safety assessed” requires an explicit tumorigenicity, adverse-event, survival, mortality, or comparable endpoint; silence is not safety.

Mixed results are represented in the narrative field and, where one overall status is unavoidable, conservatively. ORG014 is `Reported negative` for colonic engraftment even though a transient recovery signal was observed, because injected organoids did not engraft at the target injury site.
